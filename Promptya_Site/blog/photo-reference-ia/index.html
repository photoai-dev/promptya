Quelle photo de référence choisir pour un portrait IA ?

La référence est le point de départ d’une création qui doit évoquer une personne. Une photo facile à lire aide davantage qu’un selfie très retouché ou un portrait dans une lumière difficile.

Privilégier un visage visible

Choisissez une image nette avec un seul sujet principal et un visage suffisamment grand. Les lunettes très sombres, les cheveux devant les yeux et les filtres qui redessinent les traits masquent des informations utiles. Une expression naturelle facilite ensuite la comparaison entre la référence et le résultat.

Préférer une lumière régulière

Une lumière douce de fenêtre peut rendre les volumes lisibles sans ombre très dure. Évitez les éclairages colorés qui transforment fortement le teint si votre objectif est un portrait naturel. L’arrière-plan n’a pas besoin d’être remarquable : il doit surtout laisser le sujet se distinguer clairement.

Vérifier le mode sélectionné

Tous les modèles ne travaillent pas à partir d’une photo. Dans le studio, utilisez un mode annoncé comme compatible avec une référence et respectez les formats de fichier indiqués. La référence guide l’image sans garantir une copie exacte ; relisez les traits et les proportions avant toute publication.

UN EXEMPLE POUR AVANCER

Mettre cette idée en pratique

Un portrait de face ou légèrement de trois quarts, avec une expression calme et un arrière-plan simple, constitue un bon point de départ. Gardez l’original afin de pouvoir vérifier les résultats sans vous fier uniquement à votre mémoire.

Avant de choisir vos images

  • Un visage net et dégagé.
  • Une lumière facile à interpréter.
  • Une photo dont vous pouvez autoriser l’utilisation.

Pour préparer votre série, consultez aussi le fonctionnement du studio et les forfaits et leurs montants totaux.
