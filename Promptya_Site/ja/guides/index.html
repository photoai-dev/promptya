役立つプロンプトによって階層が確立されます。主題とその行動が最初にあります。次に、装飾、額装、照明について、シーンの見方を説明します。主要なアイデアと矛盾することなく、詳細を設定することで仕事が完了します。

01

主題

誰に、あるいは何を注目させるべきでしょうか？役立つ特性、服装、わかりやすいアクションを示します。

02

フレーム

シーンはどこで行われますか?計画、被写体の場所、人物と背景の関係を指定します。

03

レンダリング

写真、3D アニメーション、描画、またはコラージュ: 主な方向を選択し、光を説明します。

04

限界

いくつかの便利な除外と形式を追加します。相反する効果を同時に求めることは避けてください。

特定する

「パリの美しい現実的な女性。信じられないほど完璧で、高品質です。」

より明確な方向性

「夜明けのパリの広場で、リネンのジャケットを着た大人の女性のエディトリアルポートレート。アメリカの計画、柔らかい横からの光、目に見える建築物、自然な肌、文字なし。」

精度は結果を保証するものではありません。プロンプトはモデルをガイドするために使用されます。つまり、一度に 1 点ずつテスト、比較、修正します。

光・素材・一貫性

フォトリアル

まずは写真映えするシチュエーションから。被写体、その動作、照明、設定の場所を説明します。正確な素材は、「完璧」や「超リアル」といった言葉の積み重ね以上のものをもたらします。

即時の例

早朝、パリの広場に立つ、ベージュのリネンジャケットを着た大人の女性のエディトリアル写真。アメリカのショット、中心からわずかにずれた被写体、背景の建築物。左側から差し込む柔らかな自然光、目に見えるリネンの質感、自然な肌、一貫した影。クリームとストーンのパレット、適度な被写界深度。文字やロゴなし。

なぜこの構造になっているのでしょうか？ フレーミング、素材、光の方向が一貫したシーンを表現します。

ボリューム、アクション、ユニバース

アニメーションと 3D

視覚言語を指定します: 3D アニメ映画、2D イラスト、またはモデリング粘土ボリューム。画像が何かを語るように、キャラクターに簡単なアクションと設定のスケール ルールを与えます。

即時の例

3D アニメ映画のワンシーン: 丸眼鏡と青いコートを着たミニチュアの大人の図書館員が、巨大な本の間に木製のはしごを押しています。本はその10倍の大きさです。丸みを帯びたボリューム、触感のある素材、読みやすい表現、電気スタンドの温かみのある照明。風景の構成、前景のキャラクター、単一の主要なアクション。テキストやブランド表記なし。

なぜこの構造になっているのでしょうか？ スタイル、アクション、スケールの関係が、小さな世界に読みやすい方向性を与えます。

アイデンティティ・表現・フレーミング

顔とリファレンス

認識可能なものを維持しなければならないものと、変化する可能性のあるものを分離します。明確な参照はモデルが顔を読み取るのに役立ちますが、同一性を保証するものではありません。使用を許可された写真を使用してください。

即時の例

許可された参照写真から、同じ成人の写真ポートレートを作成します。彼の特徴的な特徴と髪型を可能な限り維持してください。リラックスした表情、レンズに向かう視線、頭と肩のフレーミング、無地のパール グレーの背景。拡散照明、自然な肌の質感、美容フィルターは適用されていません。メガネや文字を追加しないでください。

なぜこの構造になっているのでしょうか？ リファレンスはベンチマークとして機能しますが、式とフレームワークは明示的に定義されたままになります。

シルエット・コントラスト・キャラクター

バイラルトレンドキャラクター

主な誇張と個性を選択してください。競合する異常が多すぎると、シルエットがぼやけます。不条理なものがすぐに目に見えるように、写真素材と明確な態度を保ちます。

即時の例

架空の成人キャラクターの宣伝用ポートレート写真。巨大な螺旋状の口ひげを生やし、紫色のスーツと白い手袋をした小柄な貴族。彼は非常に小さなカップを非常に真剣な表情で調べます。ラベンダーのスタジオ背景、側面の柔らかな光、詳細なベルベットと磁器。読みやすいシルエット、エレガントなビジュアルユーモア、16:9 フォーマット。文字やロゴはありません。

なぜこの構造になっているのでしょうか？ 強力な異常性、認識可能なコスチューム、およびアクションは、キャラクターを確立するのに十分です。

アイデアから構造化された概要まで

きれいな JSON。
読み取れる意図。

JSON は、ブリーフをフィールドに編成する方法です。画像を自動的に改善するわけではありません。その目的は、決定を分離し、構造を再利用し、矛盾を特定することにあります。

構文

二重引用符で囲まれたキーと文字列、要素間のコンマ、末尾のコンマ、コメントは不要です。

一貫性

互換性のあるライト、フレーミング、アクション。リストは短くし、重要な詳細を説明します。

互換性

この概要は教育モデルです。 API のフィールドはサービスによって異なります。それらは普遍的なものではありません。

あなたのワークショップ

概要を作成します。

開始された世代はありません。このワークショップでは概要を準備するだけです。

概要-creatif.json
{
  "subject": "リネンジャケットを着た大人の人",
  "action": "地中海の路地を歩く",
  "style": "リアルなエディトリアル写真",
  "setting": "明るいファサード、青いシャッター、敷石",
  "lighting": "柔らかな自然の朝の光",
  "composition": {
    "framing": "アメリカの計画",
    "placement": "被写体を画面の右側3分の1に配置",
    "format": "16:9"
  },
  "palette": [
    "クリーム色",
    "青",
    "テラコッタ"
  ],
  "avoid": [
    "文字、ロゴ、過度な美化フィルター"
  ]
}

✓ 有効な JSON · ツールに適応する準備ができています

この概要を改善するにはどうすればよいでしょうか?

単一の意図から始めて、一度に 1 つのフィールドを変更します。被写体を見失った場合は、設定を簡略化するか、フレーミングを近づけてください。スタイルに一貫性がない場合は、矛盾する形容詞を削除します。シリーズの場合は、スタイル、ライト、パレットのフィールドを保持し、ポーズやアクションを変更します。

ツールがテキストによる説明を必要とする場合は、フィールドを文に言い換えます。構造を受け入れる場合は、このツールで文書化されたキーのみを使用してください。ブリーフ内の「回避」フィールドは、テンプレートに否定的なプロンプト設定があることを意味するものではありません。

役立つ質問。

非常に長いプロンプトが必要ですか?

必ずしもそうとは限りません。短くて一貫したテキストは、競合する命令のリストよりも明確にモデルをガイドできます。実際に望ましい結果を変更する場合は、詳細を追加します。

JSON はテキストよりも効率的ですか?

JSON は情報を整理しますが、品質や忠実性は保証されません。受け入れられる形式はツールによって異なります。概要の判読可能なバージョンを保持し、使用するモデルに合わせて変更します。

認識可能な顔を維持するにはどうすればよいですか?

互換性のあるモデルで認可された読み取り可能なリファレンスを使用してください。保持すべき特性を説明し、結果を比較します。類似性は異なる場合があるため、確認する必要があります。

このページの例はパックのプロンプトですか?

いいえ、これらは公的教育の例です。パックに使用される内部シナリオとテキストはオファーに含まれません。コマンドはイメージを配信します。
