Das Modell schneidet Ihr Bild genau zu. Es simuliert keine neue Generation von KI.

Separater Preis muss definiert werden. Für Cover sind keine Käufe oder kostenpflichtige KI-Generierung aktiviert. Mit dem Konfigurator können Sie bereits Ihre Zusammenstellung und Ihr Briefing vorbereiten.

Vorgeschriebenes Format: 1:1 · Kompositionsmodell. Das erste Bild ist Ihr bereitgestelltes Beispiel, keine neue Generation.

Ein Albumcover, das für Ihre Musik entworfen wurde.

Ein Cover muss in kleiner Größe lesbar bleiben, dem Namen des Künstlers und dem Titel einen klaren Platz geben und das Klanguniversum des Projekts widerspiegeln. Das quadratische Format ist im Konfigurator keine Option: Die Seite bleibt 1:1 erhalten, unabhängig vom geladenen Bild.

Das Studio bereitet eine Porträt-, Kino-, Minimalismus- oder Surrealismus-Regie vor. Die KI-Generierung wird aktiviert, nachdem der Preis definiert und das Modell verbunden wurde. Fotopaketpakete sind von diesem Musikangebot getrennt.
