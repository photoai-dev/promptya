Eine gute Basis verändert alles

Beschreiben Sie eine Szene.
Geben Sie die Richtung vor.

Eine hilfreiche Eingabeaufforderung legt die Hierarchie fest. Das Subjekt und seine Handlung stehen an erster Stelle; Die Dekoration, der Rahmen und die Beleuchtung erklären dann, wie man die Szene betrachtet. Die Details runden die Arbeit ab, ohne der Hauptidee zu widersprechen.

01

Das Thema

Wer oder was soll die Blicke auf sich ziehen? Geben Sie nützliche Eigenschaften, Outfit und verständliche Handlungen an.

02

Der Rahmen

Wo spielt die Szene? Geben Sie den Plan, den Ort des Motivs und die Beziehung zwischen der Person und der Umgebung an.

03

Das Rendering

Fotografie, 3D-Animation, Zeichnung oder Collage: Wählen Sie eine Hauptrichtung und beschreiben Sie das Licht.

04

Die Grenzen

Fügen Sie einige nützliche Ausschlüsse und Formate hinzu. Vermeiden Sie es, gleichzeitig nach widersprüchlichen Wirkungen zu fragen.

MUSS ANGEGEBEN WERDEN

„Eine wunderschöne realistische Frau in Paris, unglaublich, perfekt, in hoher Qualität. »

KLARERE RICHTUNG

„Redaktionelles Porträt einer erwachsenen Frau in einer Leinenjacke auf einem Pariser Platz im Morgengrauen. Amerikanischer Grundriss, sanftes Seitenlicht, sichtbare Architektur, natürliche Haut, ohne Text. »

Präzision ist keine Garantie für Ergebnisse. Eine Eingabeaufforderung dient zur Führung eines Modells: Testen, vergleichen und korrigieren Sie jeweils einen Punkt.

LICHT · MATERIALIEN · KOHÄRENZ

Fotorealistisch

Beginnen Sie mit einer fotografierbaren Situation. Beschreiben Sie das Motiv, was es tut, das Licht und den Ort der Einstellung. Ein präzises Material bringt mehr als eine Ansammlung von Wörtern wie „perfekt“ oder „ultrarealistisch“.

PROMPT-BEISPIEL

Redaktionelles Foto einer erwachsenen Frau in einer beigen Leinenjacke, die am frühen Morgen auf einem Pariser Platz steht. Amerikanische Aufnahme, Motiv leicht außermittig, Architektur im Hintergrund. Weiches, natürliches Licht von links, sichtbare Leinenstruktur, natürliche Haut und gleichmäßige Schatten. Creme- und Steinpalette, mäßige Schärfentiefe. Ohne Text oder Logo.

Warum diese Struktur? Der Bildausschnitt, das Material und die Lichtrichtung beschreiben eine zusammenhängende Szene.

IDENTITÄT · AUSDRUCK · RAHMEN

Gesicht & Referenz

Trennen Sie, was erkennbar bleiben muss, von dem, was sich ändern kann. Eine eindeutige Referenz hilft dem Modell, das Gesicht zu erkennen, garantiert jedoch keine identische Identität. Verwenden Sie ein Foto, zu dessen Verwendung Sie berechtigt sind.

PROMPT-BEISPIEL

Erstellen Sie aus dem autorisierten Referenzfoto ein fotografisches Porträt derselben erwachsenen Person. Behalten Sie seine besonderen Merkmale und seine Frisur so weit wie möglich bei. Entspannter Gesichtsausdruck, Blick auf die Linse, Kopf- und Schulterrahmen, schlichter perlgrauer Hintergrund. Diffuses Licht, natürliche Hautstruktur, kein Schönheitsfilter angewendet. Fügen Sie keine Brille oder Text hinzu.

Warum diese Struktur? Die Referenz dient als Maßstab, während der Ausdruck und der Rahmen explizit definiert bleiben.

Fotografisches Werbeporträt einer fiktiven erwachsenen Figur: ein kleiner Aristokrat mit einem monumentalen spiralförmigen Schnurrbart, einem taillierten lila Anzug und weißen Handschuhen. VON DER IDEE ZUM STRUKTURIERTEN BRIEF

Ein sauberer JSON.
Eine lesbare Absicht.

JSON ist eine Möglichkeit, Ihr Briefing in Felder zu gliedern. Es macht ein Bild nicht automatisch besser: Sein Interesse liegt darin, Entscheidungen zu trennen, eine Struktur wiederzuverwenden und Widersprüche zu erkennen.

Syntax

Schlüssel und Zeichenfolgen in doppelten Anführungszeichen, Kommas zwischen Elementen, keine abschließenden Kommas, keine Kommentare.

Konsistenz

Kompatibles Licht, Bildausschnitt und Aktion. Halten Sie die Listen kurz und beschreiben Sie die Details, auf die es ankommt.

Kompatibilität

Bei diesem Brief handelt es sich um ein pädagogisches Modell. Die Felder in einer API hängen vom Dienst ab; sie sind nicht universell.

IHRE WERKSTATT

Verfassen Sie Ihr Briefing.

Es wurde noch keine Generation gestartet: In diesem Workshop wird lediglich Ihr Briefing vorbereitet.

brief-creatif.json
{
  "subject": "Eine erwachsene Person in einer Leinenjacke",
  "action": "Spazieren Sie durch eine mediterrane Gasse",
  "style": "Realistische redaktionelle Fotografie",
  "setting": "Helle Fassaden, blaue Fensterläden und Pflastersteine",
  "lighting": "Sanftes natürliches Morgenlicht",
  "composition": {
    "framing": "Amerikanischer Plan",
    "placement": "Person im rechten Bilddrittel",
    "format": "16:9"
  },
  "palette": [
    "Creme",
    "Blau",
    "Terrakotta"
  ],
  "avoid": [
    "Text",
    "Logo",
    "übermäßiger Schönheitsfilter"
  ]
}

✓ Gültiges JSON · bereit zur Anpassung an Ihr Tool

Wie kann dieses Briefing verbessert werden?

Beginnen Sie mit einer einzigen Absicht und ändern Sie dann jeweils ein Feld. Wenn das Motiv verloren geht, vereinfachen Sie die Einstellung oder verkleinern Sie den Bildausschnitt. Wenn es dem Stil an Konsistenz mangelt, entfernen Sie widersprüchliche Adjektive. Behalten Sie für eine Serie die Felder „Stil“, „Licht“ und „Palette“ bei und variieren Sie dann die Pose oder Aktion.

Wenn ein Tool eine Textbeschreibung erwartet, formulieren Sie die Felder in Sätze um. Wenn es eine Struktur akzeptiert, verwenden Sie nur die von diesem Tool dokumentierten Schlüssel. Ein „Vermeiden“-Feld in einem Brief bedeutet nicht, dass die Vorlage eine negative Eingabeaufforderungseinstellung hat.

BEVOR SIE EIN BILD AUFBEWAHREN

Schauen Sie sich die Details an.
Behalten Sie die Absicht bei.

Ein ansprechendes Miniaturbild kann Inkonsistenzen im Großen und Ganzen aufdecken. Vergleichen Sie das Ergebnis mit Ihrem Briefing, bevor Sie es veröffentlichen.

  • Das Thema — einheitliches Gesicht, Hände, Accessoires und Silhouette.
  • Die Szene — Schatten, Reflexionen, Kontakte und plausible Perspektiven.
  • Die Unterstützung — Nützliche Rahmen, Textfelder und klein lesbare Details.
  • Die Serie — eine stabile Palette, Licht und Benchmarks zwischen Bildern.
WEITER GEHEN

Nützliche Fragen.

Ist eine sehr lange Eingabeaufforderung notwendig?

Nicht unbedingt. Ein kurzer, zusammenhängender Text kann das Modell klarer leiten als eine Liste konkurrierender Anweisungen. Fügen Sie ein Detail hinzu, wenn es tatsächlich das gewünschte Ergebnis verändert.

Ist JSON effizienter als Text?

JSON organisiert Informationen, garantiert jedoch weder Qualität noch Treue. Das akzeptierte Format hängt vom Tool ab. Halten Sie eine lesbare Version des Briefings bereit und passen Sie diese an das verwendete Modell an.

Wie behält man ein erkennbares Gesicht?

Verwenden Sie eine autorisierte und lesbare Referenz mit einem kompatiblen Modell. Beschreiben Sie die Merkmale, die beibehalten werden sollen, und vergleichen Sie dann die Ergebnisse. Die Ähnlichkeit kann variieren und sollte überprüft werden.

Sind die Beispiele auf dieser Seite die Pack-Prompts?

Nein. Es handelt sich um öffentliche Bildungsbeispiele. Die für die Pakete verwendeten internen Szenarien und Texte sind nicht im Angebot enthalten; Befehle liefern Bilder.
