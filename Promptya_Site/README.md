# Promptya — véritable site multipage statique

Ouvrir index.html ou lancer `python -m http.server 8000` dans le dossier. Les chemins absolus `/packs/...` fonctionnent avec un serveur configuré à la racine.

Site public : page accueil + catalogue + 106 pages packs + Viral Trend + Adult Prompt + Studio + Tarifs + Guides, chaque URL avec son propre HTML, titre, description et canonical. 8 487 prompts extraits et 12 prompts montrés sur chaque page pack.

IMPORTANT : prototype statique SEO. La génération réelle Replicate, les paiements, comptes, ZIP et livraison automatique nécessitent un serveur et des secrets API. Les fonctionnalités non connectées sont signalées en démonstration. Le tarif 19,90 € concerne le pack 100 images.

Les visuels proviennent des fichiers fournis par le client. Vérifier les droits de publication, autorisations des modèles et marques avant déploiement.
